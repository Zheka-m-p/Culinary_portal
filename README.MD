# 🍲 Кулинарный портал на Django (Culinary Portal)

Полноценный веб-портал для публикации, просмотра и обсуждения кулинарных рецептов. Проект написан на Django с использованием Class-Based Views (CBV), Bootstrap 5 и Vanilla JavaScript (Fetch API) для асинхронной работы.

## ✨ Основные возможности (Features)

* **Аутентификация:** Полноценная система регистрации, входа и выхода пользователей.
* **CRUD для рецептов:** Создание, чтение, редактирование и удаление постов. Загрузка фотографий к рецептам.
* **Система прав (Безопасность):** Редактировать и удалять рецепты может только их автор (реализовано через `UserPassesTestMixin` и проверки в шаблонах).
* **Комментарии с AJAX:** Возможность оставлять комментарии. Редактирование и удаление комментариев происходит **без перезагрузки страницы** (Fetch API + JSON). Автор поста может модерировать (удалять) любые комментарии под своим рецептом.
* **Категории и поиск:** Динамическая фильтрация рецептов по категориям. Поиск по названию и содержимому рецепта.
* **Профиль пользователя:** Личная страница с информацией о пользователе и списком его статей.
* **Счетчик просмотров:** Атомарное увеличение счетчика просмотров через `F()`-выражения (защита от race condition).
* **Адаптивный дизайн:** Верстка на Bootstrap 5, корректно отображается на мобильных устройствах и ПК.

## 🛠️ Стек технологий (Tech Stack)

* **Backend:** Python 3.x, Django 5.x
* **База данных:** SQLite (для локальной разработки)
* **Frontend:** HTML5, CSS3, Bootstrap 5.3, Bootstrap Icons
* **JavaScript:** Vanilla JS (Fetch API для AJAX-запросов)
* **Архитектура:** Class-Based Views (`ListView`, `DetailView`, `CreateView`, `UpdateView`, `DeleteView`)

## 🚀 Как запустить проект локально (Installation)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_НИК/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
   cd НАЗВАНИЕ_РЕПОЗИТОРИЯ
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для Mac/Linux:
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта (рядом с `manage.py`) и добавьте туда:
   ```env
   SECRET_KEY=ваш_секретный_ключ_джанго
   DEBUG=True
   ```
   *(Секретный ключ можно сгенерировать командой `python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"`)*

5. **Примените миграции:**
   ```bash
   python manage.py migrate
   ```

6. **Создайте суперпользователя (админа):**
   ```bash
   python manage.py createsuperuser
   ```

7. **Запустите сервер разработки:**
   ```bash
   python manage.py runserver
   ```
   После запуска проект будет доступен в браузере по адресу: `http://127.0.0.1:8000/`

## 📂 Структура проекта

* `cooking/` — основное приложение: модели постов, категорий, комментариев, представления (views) и шаблоны.
* `users/` — приложение для работы с пользователями (профили, регистрация, аутентификация).
* `templates/` — глобальные шаблоны (`base.html`, `navbar`, `footer`, системные сообщения).
* `media/` — загруженные пользователями файлы (фотографии рецептов). Директория исключена из Git.
